# 한국어 서지와 판본

## 저작·판본·번역을 구분하라

저자와 제목이 같아도 원저, 개정판, 재판, 번역본, 전집 수록본, 논문 재수록본은 다른 인용 대상일 수 있다. 실제 읽은 판본을 기록하고 다른 판본의 쪽수를 가져오지 마라. 저자의 성명 한글·한자·로마자 표기를 추정으로 교체하지 마라.

| 자료 유형 | 우선 확인할 사항 |
|---|---|
| 한국어 학술논문 | 저자, 정확한 제목, 학술지, 발행 기관, 연도, 권·호, 수록 쪽, DOI가 있으면 DOI |
| 단행본 | 저자·편자, 제목, 판·쇄 구분, 출판사, 발행 연도, 사용 판본, ISBN이 있으면 ISBN |
| 번역서 | 원저자, 역자, 번역 제목, 번역본 출판사·연도·판본, 확인한 경우 원저 서지 |
| 학위논문 | 저자, 제목, 학위 수준, 수여 대학, 연도, 실제 이용한 저장소·파일 |
| 잡지·신문·초기 온라인 문헌 | 필자·필명, 제목, 매체, 발행일 또는 호수, 수록 위치, 원본·복각·웹 아카이브 구분 |
| 웹페이지 | 작성 주체, 제목, 표시된 작성·수정일, URL, 접근일, 직접 읽은 범위 |

표의 모든 칸을 무조건 채우려고 추정하지 마라. 확인되지 않은 값은 연구 기록에서 미확인으로 남겨라. 발행 연도, 온라인 공개일, 수정일, 저장소 업로드일을 혼용하지 마라.

## 인쇄 쪽과 PDF 위치를 분리하라

직접 인용의 쪽수는 원칙적으로 해당 판본의 인쇄 쪽을 사용하라. 재현 가능한 위치 기록에는 필요에 따라 PDF 뷰어 쪽을 함께 남겨라.

예시 기록: `인쇄 p. 37 / PDF 뷰어 45쪽 / 사용 판본: 참고문헌의 해당 번역본`.

인쇄 쪽이 없는 스캔에는 `인쇄 쪽 확인 불가; PDF 뷰어 45쪽`처럼 구별하라. 로마숫자 서문, 권별 쪽, 합본, 문서 삽입면 때문에 생긴 차이를 고정 오프셋으로 단정하지 마라. 번역본 구절을 원전의 직접 인용처럼 제시하지 마라. 원전을 읽지 않았으면 원전 검증을 완료했다고 표시하지 마라.

## DOI 없음과 검증 실패를 분리하라

DOI가 없다는 사실은 문헌이 가짜라는 뜻이 아니다. 특히 단행본·옛 학술지·학위논문·사료는 해당 자료 유형의 확인 경로를 사용하라.

| 상태 | 해석과 처리 |
|---|---|
| DOI 또는 다른 식별자 일치 | 등록 서지와 실제 인용 저작·판본이 일치하는지 추가 확인 |
| DOI 미확인 또는 미부여 | 출판사·학회·도서관·대학 저장소 등의 기록으로 실재 확인 |
| 서지는 확인, 본문 미접근 | 실재만 확인; 세부 주장·직접 인용 검증은 보류 |
| 자료 간 서지 불일치 | 제목·연도·권호·판본 중 불일치 항목과 각 출처 기록 |
| 확인 경로에서 찾지 못함 | `UNRESOLVED`로 기록; 부재·위조라고 단정하지 않음 |

일반 검색 결과의 짧은 문구를 최종 서지 근거로 삼기 전에 원자료 기록을 열어라. KCI·RISS·DBpia·도서관·출판사·학회·대학 저장소 중 실제 이용 가능한 경로를 선택하라. 서로 복제된 검색 결과 여러 개를 독립된 교차 검증으로 세지 마라.

## 인용 형식을 맞추라

사용자가 제공한 학술지 규정이 있으면 그 규정의 판과 확인 날짜를 따르라. 국내 학술지에 APA·Chicago·MLA 중 하나를 임의로 강제하지 마라. 규정이 없으면 사용자의 기존 원고 형식을 일관되게 유지하고 필요 시 형식 선택을 짧게 제안하라.

한국어·한자·로마자 문헌의 배열, 『단행본』·「논문」 표기, 역자·편자 표기, 재인용 방식은 적용 중인 규정에 맞추어라. 서지 데이터를 정규화하는 작업과 저자가 인용한 실제 판본을 바꾸는 작업을 구분하라.

## 재인용과 OCR

원전을 읽지 않고 2차 문헌에서 인용문을 발견했다면 재인용임을 표시하라. 원전 확인을 시도할 수 있으면 직접 확인한 뒤에만 재인용 표시를 바꾸어라. OCR 텍스트의 한자, 고어, 숫자, 각주 표식, 부정어가 의심되면 스캔 화면과 대조하라. 자동 교정으로 원문의 표현을 현대어로 바꾼 뒤 직접 인용부호를 유지하지 마라.
