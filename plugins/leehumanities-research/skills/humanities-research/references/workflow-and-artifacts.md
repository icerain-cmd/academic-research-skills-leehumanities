# 진행과 산출물

## 작업 범위를 먼저 정하라

대화와 제공 파일에서 이번 산출물, 대상 독자나 학술지, 원고 언어, 확정된 주장, 자료 접근 범위, 필요한 길이를 읽어라. 빠진 값은 꼭 필요한 것만 물어라. 학술지가 정해지지 않았으면 투고 형식을 임의로 확정하지 말고 연구 원고를 작성하라.

사용자에게 이미 승인받은 계획·조사·집필·수정 권한을 유지하라. 읽기, 작업 메모, 초고 작성, 정해진 범위의 교정을 할 때마다 허락을 다시 요구하지 마라. 새로운 외부 게시·투고·메시지 전송, 자료의 공개 범위 변경, 중심 논지의 대체가 필요하면 검토 가능한 구체적 결과를 먼저 만든 뒤 그 선택만 확인하라. 이전에 해당 외부 조치까지 승인받았으면 같은 허락을 다시 요구하지 마라.

## 요청에 맞게 진행하라

### 계획과 조사

제공 자료를 읽고 문제의식과 개념의 계보를 잡아라. 저자의 개념을 설명하는 자료와 그 개념을 비판·비교하는 외부 자료를 모두 확보하라. 문헌을 모으는 중에도 무엇을 찾았고 무엇을 아직 확인하지 못했는지 갱신하라. 처음 설정한 해석에 맞는 문헌만 남기지 마라.

### 집필

원고 전체를 요청받으면 현재 근거로 성립하는 전체 초고를 작성하라. 핵심 자료가 없으면 해당 주장을 약화·제거하거나 대안 논증을 사용하고, 그 이유를 별도 메모에 남겨라. 알 수 없는 원전 문구나 쪽수를 채워 넣지 마라. 다른 부분을 진행할 수 있으면 그 부분부터 완성하라.

### 검토와 수정

집필자의 판단과 구분되는 논증 비판 및 출처 검증을 수행하라. 원고 위치에 근거한 문제를 우선하라. 승인된 수정 범위에 따라 고치되 저자의 중심 개념을 바꿀 필요가 있으면 이유와 대안을 제시하라. 수정으로 바뀐 인용·초록·결론을 함께 재검토하라. 검토 횟수를 채우기 위한 반복은 하지 마라.

### 마무리

논문 파일, 검토 범위, 미해결 핵심 쟁점, 실제 도구 실행 결과를 전달하라. 형식 검사가 통과했어도 근거가 미확인이라면 “투고 준비 완료”라고 쓰지 마라. 경미한 서지 정리와 중심 논증의 증거 부재를 같은 수준의 문제로 보고하지 마라.

## 산출물을 가볍게 유지하라

작업 디렉터리는 사용자가 지정한 곳을 사용하라. 지정이 없으면 현재 프로젝트 안의 연구 작업 폴더를 선택하고 경로를 알려라. 모든 요청에 모든 파일을 만들지 마라.

| 산출물 | 필요할 때 담을 내용 |
|---|---|
| 원고 | 독자가 읽는 본문, 각주·참고문헌, 요청한 초록 |
| 연구 메모 | 문제의식, 장별 논증, 경쟁 설명, 검색 범위, 미확인 사항 |
| 개념 기록 | 저자가 확정한 표현, 출처, 관계, 보류된 대안 |
| 자료목록 | 등록한 파일과 공개 출처의 식별자, 접근·열람 상태 |
| 근거 기록 | 주장별 출처·위치·대조 결과, 별도 검증 상태 |
| 검토 메모 | 원고 위치별 판단·근거·불확실성·수정 제안 |
| 수정 내역 | 실제 변경, 변경 이유, 수용하지 않은 의견과 사유 |

개인 연구 산출물은 플러그인 배포 파일과 분리하라. 공개 저장소에 커밋하거나 외부로 보내기 전에는 사용자가 허용한 공개 범위를 확인하라. 플러그인 설치 자체를 원고 공개 동의로 해석하지 마라.

## 재개할 때 확인하라

가장 최근 원고와 작업 메모, 저자가 마지막으로 수용한 표현, 남은 근거 목록을 읽어라. 과거 요약보다 원문과 실제 파일을 우선하라. 버전이 다르면 날짜·변경 이력·사용자의 명시적 지시로 기준을 정하고 서로 다른 버전을 조용히 합치지 마라. 이미 완료한 조사나 승인 단계를 처음부터 반복하지 마라.

## 역할 배정 결과를 기록하라

실제로 실행한 에이전트명, 검토 대상 버전, 수행 범위, 주요 판단을 짧게 남겨라. 별도 에이전트를 사용할 수 없어 직접 검토했으면 그 사실을 기록하라. 에이전트 수·반복 횟수·보고서 분량을 연구 품질의 대리 지표로 삼지 마라.
